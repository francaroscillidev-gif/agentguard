# Contributing to AgentGuard

Thank you for your interest in contributing to **AgentGuard**! We welcome bug reports, feature suggestions, documentation enhancements, and pull requests from developers worldwide.

---

## 🛠️ Development Setup

1. **Fork and Clone the Repository:**
   ```bash
   git clone https://github.com/francaroscillidev-gif/agentguard.git
   cd agentguard
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Build TypeScript Sources:**
   ```bash
   npm run build
   ```

4. **Run Test Suite:**
   ```bash
   npm test
   ```

---

## 🌿 Branching and Commit Guidelines

- Use descriptive branch names:
  - `feat/add-nuget-ecosystem`
  - `fix/pypi-edgecase-resolver`
  - `docs/clarify-mcp-setup`
- Follow semantic commit messages (`feat: ...`, `fix: ...`, `docs: ...`, `refactor: ...`).
- Ensure all tests pass (`npm test`) before submitting a pull request.
- Ensure the native Git pre-commit hook runs cleanly.

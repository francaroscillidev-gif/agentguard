# Security Policy

## 🛡️ Supported Versions

We actively support and release security patches for the latest major version of AgentGuard:

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x:                |

---

## 🚨 Reporting a Vulnerability

The AgentGuard team takes the security of autonomous agent runtimes, software supply chains, and developer environments extremely seriously.

If you believe you have discovered a security vulnerability (such as a bypass of the Execution Shield, an unhandled prompt injection vector, or a registry spoofing technique), please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Send an email directly to **Franca Roscilli** at:  
   📧 **[francaroscillidev@gmail.com](mailto:francaroscillidev@gmail.com)**
3. Please include:
   - Type of vulnerability and affected component (`shield_command`, `packages`, `injections`, etc.)
   - Minimal steps or payload to reproduce
   - Potential impact
   - Any proposed fix or mitigation

We will acknowledge receipt within 48 hours and work with you to coordinate a patched release before any public disclosure.
